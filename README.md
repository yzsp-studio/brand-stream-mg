## 🇬🇧 English

Give it only two things: a brand logo reference image, and a brand name, theme word or one-line brand theme; anything missing gets filled in before generation starts. The skill extracts selling points from the brand, designs a lead element such as an IP character, 3D icon or energy node, and works out the full 15-second brand stream motion-graphics structure. The default deliverable is a 15-second 16:9 brand MG video, and a high-resolution, high-frame-rate video prompt is shown for review before anything is generated. Every key decision runs through option cards (duration, reference images, theme direction, whether to keep the original lettering, visual texture, generate now or not) instead of asking you to type long confirmations. If the logo has no text, the finished piece must not invent any.

### ✨ What it does

- Logo image + brand name/theme in, 15-second 16:9 brand stream MG video out
- Extracts brand selling points and drives the full IP lead-character workflow
- Optional 3D icon or energy-node lead element that carries the brand thread
- Produces a high-resolution, high-frame-rate video prompt for review before generating
- Option cards for duration, theme direction, visual texture and keeping original lettering
- Text-free logos stay text-free, so the brand mark is never rewritten
